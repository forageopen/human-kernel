# Code of Conduct

Human Kernel is a small, early-stage open source project. This document is written in the spirit of the Contributor Covenant, in plain language rather than reproduced legal text.

## Expected Behavior

- Engage with ideas and code, not people. Critique the PR, not the contributor.
- Assume good faith, especially in async review comments where tone is easy to misread.
- Disagreements about architecture (storage engine, schema shape, module boundaries) are normal and expected — resolve them with the ADR process (`CONTRIBUTING.md`), not by escalation or repetition until someone gives up.
- Respect the project's stated non-negotiable principles (Brief v2 §10) even when they're inconvenient. Arguing that a principle is wrong is fair game in an issue; quietly shipping code that violates it is not.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language or imagery, in any project space (issues, PRs, discussions).
- Publishing others' private information — including course participants' data, given this project's courseware context (see `human-kernel-privacy-policy.md`) — without explicit consent.
- Sustained disruption of discussion or deliberate derailing of technical review.

## Scope

This applies to all project spaces: the repository, issues, pull requests, and any official Human Kernel communication channel.

## Enforcement

Report concerns to the project maintainer (Adam Rosman). Reports will be handled discreetly. Consequences range from a private warning to removal from the project, at the maintainer's discretion, scaled to severity.
